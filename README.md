# RETAILBI-Business_Intelligence

Análisis de datos comerciales y ventas minoristas mediante herramientas de Business Intelligence (BI).

## Descripción del proyecto

Este proyecto tiene como objetivo organizar, explorar y analizar datos relacionados con el comercio minorista para identificar patrones de ventas, comprender el comportamiento de los datos comerciales y generar información útil para la toma de decisiones.

El repositorio reúne diferentes conjuntos de datos que servirán como base para desarrollar análisis exploratorios, visualizaciones e indicadores de negocio.

## Objetivos

- Organizar y documentar los conjuntos de datos utilizados en el proyecto.
- Explorar información relacionada con las ventas y el comercio minorista.
- Identificar tendencias y patrones relevantes en los datos.
- Preparar información para la construcción de indicadores y visualizaciones.
- Aplicar herramientas de análisis de datos e inteligencia de negocios.
- Documentar el proceso de desarrollo y los resultados obtenidos.

## Conjuntos de datos

### 1. RetailBI — Ventas sintéticas

**Archivo:** `RetailBI_ventas_sinteticas_50000.gpkg`

Archivo GeoPackage que contiene datos estructurados en un formato compatible con herramientas de información geográfica.

Se utilizará para explorar la información disponible y determinar su utilidad dentro del análisis comercial.

### 2. Datos en formato CSV

**Archivo:** `170b171a-19bb-46ca-83e8-3074fe7d74be.csv`

Archivo tabular que se incorporará al proceso de exploración y análisis.

Sus columnas, variables y relaciones deberán documentarse después de examinar su contenido.

### 3. Información de comercio minorista

**Archivo:** `anex-EMC-ComercioMinorista-ago2026.xlsx`

Archivo de Excel relacionado con información del comercio minorista.

Se analizará para conocer las variables disponibles y evaluar su utilidad para complementar el estudio comercial.

> Nota: la estructura, el significado de las variables y la relación entre los conjuntos de datos deben verificarse antes de realizar análisis conjuntos.

## Metodología de trabajo

El proyecto se desarrollará progresivamente mediante las siguientes etapas:

1. **Exploración de datos:** identificar las columnas, los tipos de datos y la estructura de cada archivo.
2. **Limpieza y preparación:** detectar valores faltantes, duplicados e inconsistencias.
3. **Análisis exploratorio:** calcular estadísticas y buscar patrones relevantes.
4. **Integración de datos:** relacionar las fuentes cuando exista una correspondencia válida entre sus variables.
5. **Visualización:** desarrollar gráficos e indicadores que faciliten la interpretación de los resultados.
6. **Conclusiones:** documentar los hallazgos y las posibles aplicaciones para la toma de decisiones.

## Herramientas

Las herramientas se definirán según las necesidades del análisis. Entre las opciones que se pueden evaluar están:

- Python para la exploración y el procesamiento de datos.
- Pandas para la manipulación de datos tabulares.
- Jupyter Notebook para documentar el análisis.
- Power BI para construir visualizaciones e indicadores.
- Git y GitHub para el control de versiones y la documentación.
- QGIS para explorar la información geográfica del archivo GeoPackage, si corresponde.

Estas herramientas son opciones previstas; no implica que todas se hayan utilizado ya.
